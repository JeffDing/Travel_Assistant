# 春节旅游计划AI小助手

基于 Gradio 和 ModelArts Studio API 构建的智能旅游规划助手，帮助您轻松规划春节假期旅行。

## 功能特性

### 1. 目的地推荐
- 支持选择或手动输入国家、城市
- AI 动态获取热门国家和城市列表
- 推荐当地知名景点
- 提供未来天气情况预测
- 给出春节期间游览建议

### 2. 景点查询
- 输入任意景点名称
- 获取详细景点介绍和历史背景
- 推荐最佳游览时间和路线
- 提供天气信息和春节游览提示

### 3. 路线规划
- 支持自驾和公共交通两种方式
- 提供详细路线规划
- 预估时间和费用
- 春节出行特别提示

## 环境要求

- Python 3.8+
- 依赖包见 `requirements.txt`

## 环境变量配置

运行前需要设置以下环境变量：

| 环境变量 | 说明 |
|---------|------|
| `API_URL` | AI API 服务地址 |
| `MODEL_NAME` | 使用的模型名称 |
| `API_KEY` | API 访问密钥 |

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

在 `run.sh` 中设置环境变量：

```bash
export API_URL="your_api_url"
export MODEL_NAME="your_model_name"
export API_KEY="your_api_key"
```

### 3. 启动应用

```bash
chmod +x run.sh
./run.sh
```

或直接运行：

```bash
python app.py
```

应用将在 `http://0.0.0.0:7860` 启动。

## 使用说明

1. **目的地推荐**：选择或输入国家和城市，点击"获取推荐"获取景点和天气信息
2. **景点查询**：输入景点名称，点击"查询景点"获取详细介绍
3. **路线规划**：输入出发地、目的地和交通方式，点击"规划路线"获取出行方案

## 注意事项

- AI 生成的内容仅供参考，实际出行请以官方信息为准
- 首次加载国家列表可能需要几秒钟
- 支持手动输入小众国家或城市名称

## 技术栈

- **AI 能力**: ModelArts Studio API
